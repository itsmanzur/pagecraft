# Sekkei 60-Second Demo Video Script

Goal: show why Sekkei exists without overexplaining.

## Title

Before publishing Elementor pages, run Sekkei.

## Shot List

1. Open Elementor editor and click the Sekkei floating button.
2. Show Section Planner synced with existing Elementor containers.
3. Add or review a section.
4. Open Checklist and check a few launch items.
5. Open Audit and click Run Scan.
6. Open Notes and add a handoff/revision note.
7. Open Export and show Download JSON / Restore Backup.
8. Close with: "Plan, check, audit, and hand off Elementor projects inside the editor."

## Voiceover

"Sekkei is a lightweight workflow toolkit for Elementor. It does not add frontend widgets or slow down your site. Use it to plan sections, track design QA, collect project notes, run a pre-publish audit, and export handoff data before the client review."

## CTA

Install Sekkei from WordPress.org and run it before publishing your next Elementor page.
