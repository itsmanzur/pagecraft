Market Position

Core thesis: Essential Addons, ElementsKit, Premium Addons, Royal, Happy Addons, Unlimited Elements, The Plus Addons mostly compete on widgets/templates/builders. Sekkei should compete on planning, QA, notes, CSS workflow, project handoff, and client/agency operations inside Elementor.

My Strategic Advice

Do not become another widget pack

That market is crowded and dominated by teams with hundreds of widgets/templates. Sekkei should stay fast, focused, and useful beside any Elementor setup.

Own the phrase “pre-publish audit for Elementor”

This is easy to explain, easy to demo, and painful enough that freelancers will install it.

Build in public

Release small weekly updates, write changelogs clearly, post short videos: “before publishing, run Sekkei audit”.

Win Bengali + agency niche first

Bangla-friendly typography, local freelancer workflow, and client handoff can make Sekkei memorable before going broad.

Pro Version Strategy

Recommended structure: keep Sekkei free on WordPress.org and sell Sekkei Pro as a separate add-on plugin from your own site. The free plugin should stay useful; Pro should add agency-grade reporting, advanced audits, SOP templates, and collaboration.

Best first Pro feature

White-label client report export. It is easy to understand, easy to demo, and agencies will pay for it faster than abstract settings.

Best sales hook

“Before you publish, run Sekkei Pro and send a clean client report.” This is clearer than selling another bundle of widgets.

Pricing start

Free core, Pro Solo around $39/year, Pro Agency around $79/year, and a limited founder lifetime deal around $99-$149.

Architecture

Build `sekkei-pro` as a separate add-on plugin. Free plugin exposes hooks for modules, audits, export formats, and checklist templates.
